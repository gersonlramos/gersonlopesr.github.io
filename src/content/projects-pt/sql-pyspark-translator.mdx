## Problema

Equipes que migram workloads de warehouses SQL para Spark frequentemente precisam traduzir consultas existentes para código PySpark. Além de um `SELECT` simples, essa tradução manual precisa lidar corretamente com joins, aliases, agregações e cláusulas `GROUP BY`, o que é lento e sujeito a erros difíceis de perceber.

## Abordagem

Um lexer/parser customizado tokeniza a consulta SQL recebida, constrói uma representação intermediária, uma AST que captura a estrutura da consulta independentemente da sintaxe original, e gera código equivalente de DataFrame PySpark. O tradutor trata joins, aliases de colunas, funções de agregação e cláusulas `GROUP BY`.

## Impacto

Este é um projeto de prática autodirigida, não uma entrega divulgada para um empregador. Ele demonstra domínio da lógica de tradução SQL-Spark relacionada ao trabalho de refatoração de orquestrações Airflow com Apache Iceberg e Spark, como um artefato público e inspecionável, sem alegar substituição de um sistema de produção.
