## store-sales-forecasting
- slug/filename: `store-sales-forecasting` | category: `data-science` | order: 6
- repoUrl: https://github.com/gersonlramos/Store-Sales---Time-Series-Forecasting
- notebookUrl: https://github.com/gersonlramos/Store-Sales---Time-Series-Forecasting/blob/main/final_model/kaggle_baby_care_dormant_submission.ipynb
- What: Kaggle "Store Sales — Time Series Forecasting". Forecast 16 days of daily unit sales across
  1,782 store x product-family series for Corporacion Favorita (Ecuador retailer). Metric RMSLE. ~4.6 years history.
- Approach: hybrid ensemble — a global **direct** LightGBM (5 seeds, per-horizon lag buckets 1/2/3-4/5-16 days,
  weight ~70%) blended with a **recursive** per-family LightGBM (feeds predictions back, ~30%, wins at long
  horizons); blend weights learned + validated leave-one-out across independent 16-day contiguous holdout
  windows; post-processing hard-zeros series dormant 365+ days.
- Feature engineering: recent-level lags/rolling means (~95% of the gain over naive), promo intensity relative
  to each series' norm, day-of-week/seasonality.
- Validation: contiguous 16-day holdout windows (never random splits), paired seed comparisons.
- Metrics: LB RMSLE 0.38924, local holdout 0.38469, naive baseline (same-weekday mean) 0.52063 -> 26% better than naive.
- Learnings: biggest gains from architecture changes (per-horizon models, dead-series zeroing, adding recursive
  blend partner) not new features; several "real effects" (oil price r=-0.63 -> -0.02 after detrending; promo
  look-ahead) were confounds that collapsed at the panel edge; XGBoost indistinguishable from LightGBM seed noise.
- No repo images. No deployed demo. Leave demoUrl unset.
- Impact framing: PUBLIC KAGGLE COMPETITION / SELF-DIRECTED — not a disclosed employer engagement. Tie to
  the disclosed **Pet Premium Distribuidora** experience (sales forecasting / regression models influencing
  inventory planning) and to the "rigorous validation" discipline. Do NOT claim a business dollar outcome.
  Demonstrable value: end-to-end forecasting on a hard real-world panel, disciplined backtesting, and the
  judgment to tell a real data effect from a useful feature.

## finance-notes-rag
- slug/filename: `finance-notes-rag` | category: `data-science` | order: 7
- repoUrl: https://github.com/gersonlramos/finance-notes-rag
- notebookUrl: none (leave unset). demoUrl: none — Streamlit runs locally only (leave unset).
- Screenshot to vendor: https://raw.githubusercontent.com/gersonlramos/finance-notes-rag/main/docs/media/interface.png
  -> save to `public/projects/finance-notes-rag/interface.png` -> imagePaths: ["/projects/finance-notes-rag/interface.png"]
- What: local-first RAG over dense PDF financial statements (Clube de Regatas do Flamengo, 2022-2025), answering
  natural-language questions with grounded, cited answers. Runs entirely on a consumer laptop CPU (i5-8265U),
  no API keys, ~zero cloud cost; optional Claude API fallback.
- 7-stage pipeline: (1) Extraction — PyMuPDF4LLM + Tesseract OCR (pt) PDF->markdown; (2) Cleaning — ~7 rule-based
  transforms; (3) Chunking — fixed 512-token windows, 64-token overlap; (4) Embedding —
  paraphrase-multilingual-MiniLM-L12-v2 (ONNX, ~0.3s/chunk CPU); (5) Indexing — ChromaDB (cosine);
  (6) Retrieval — BM25 lexical + metadata year filter; (7) Generation — Ollama Llama 3.2 3B (or Qwen 2.5 7B) with citations.
- Framework: LlamaIndex. Interface: Streamlit chatbot with source highlighting.
- Key design decisions: local-first / zero-cost; **BM25 lexical beat small multilingual embeddings by ~+24 points**
  for accounting terminology; fixed chunking beat section-based (+6 pts); year-aware query filtering.
- Evaluation: deterministic script, 20 test questions — retrieval hit@k 82%, MRR 0.75, correct answers 65%,
  **correct abstention 100%** (never hallucinated missing data).
- Known limits: 3B model misreads large multi-row tables (~65%; Qwen 7B -> 71% but 2.5 min/response); generic
  terms ("total assets") retrieve poorly; OCR column alignment approximate; CPU-only ceiling.
- Impact framing: SELF-DIRECTED. Tie to disclosed experience: **Outlier AI** (built RAG pipelines + benchmark
  evaluation scripts) and **CompassUOL AI Studio** (generative AI on AWS). Demonstrable value: a fully evaluated
  RAG system with an explicit abstention guarantee, plus the empirical finding that lexical retrieval beats small
  embeddings for financial/tabular text — at zero infra cost. No business metric claims.
